# Final scope: active development stopped on 2026-10-07

The user stopped this project's active development and requested GitHub
integration of completed work. Source, tests, historical evidence and runnable
offline interfaces are retained. No automatic restart, new field research,
client acquisition or new-build migration is scheduled. This is a source
closeout, not a new release or a promotion of published semantic capabilities.

## Retained, runnable work

- Local ROFL container/build, metadata, chunk/Zstd and packet framing diagnostics.
- Exact HN `16.19.820.7193` and KR `16.19.821.7343` candidate routes, deaths,
  assists, timers, observed returns and sampled counter/item/state observations,
  subject to each capability's own supported-build and availability checks.
- Completed exact-KR packet argument/dataflow candidates, including slot-change
  requests and opt-in cooldown request fields. Image-backed paths require an
  existing matching local module file; they do not acquire one.
- CLI/API saved-output queries, original-source reconciliation, bounded numeric
  screens and exact HN/KR sampled-counter intervals, with preserved unknown and
  unavailable states. See [quick start](QUICK_START_16_19.md).

Earlier original-source checks included 880 HN sampled intervals over three
Replays and 3,160 KR intervals over eleven Replays. These establish the recorded
protocol/observation checks, not effective damage or complete event attribution.
Public tests use portable/synthetic inputs where private originals are absent;
explicit skips must remain visible.

## Riot changes and supported interface limits

The [26.20 notes](https://www.leagueoflegends.com/en-ph/news/game-updates/league-of-legends-patch-26-20-notes/)
remove third-party replay downloads while preserving players' client downloads
and viewing of their own matches. The [memory-access notice](https://support.riotgames.com/en-us/riot/performance/game-memory-access-removed-for-third-party-apps)
starts blocking unknown third-party game-memory access on October 6, 2026; its
grace period is for already approved tools. This project claims no such approval
or offline-replay exception. No new process-memory access or protection bypass
will be attempted as part of closeout.

The [official developer documentation](https://developer.riotgames.com/docs/lol#game-client-api)
documents Replay API process/playback/render/recording/sequence functions; it
does not promise raw protocol or complete entity export. Live Client Data API
documents active-game player/event data and active-player ability levels, but
that is not a guarantee of Replay availability or access to the selected private
slot object. League Client API is explicitly unsupported for third-party use.
No new adapter, game.cfg change, localhost request or online game was introduced.

Technical ability to read an existing local file does not establish Riot product
approval. The retained offline parser and exact-build experiments must not be
advertised as an approved product or a future-proof official data pipeline.
