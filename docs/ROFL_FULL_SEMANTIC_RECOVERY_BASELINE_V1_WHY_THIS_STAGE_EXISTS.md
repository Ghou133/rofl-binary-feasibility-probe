# Why this stage exists

Stage ID: `ROFL_FULL_SEMANTIC_RECOVERY_BASELINE_V1`  
Owner: `ROFL_PARSER`  
Date: `2026-08-20`

## User value

A current-build semantic baseline turns Replay protocol research from a sequence of
one-off downstream requests into one auditable fact layer. Every observed route,
entity, state update, and semantic event remains discoverable with an exact build,
evidence grade, provenance, and explicit limitation. Consumers can use canonical
semantic types instead of importing packet IDs or decoder internals.

## North Star value

The baseline strengthens the high-precision ROFL evidence tier used for precise
features and for calibration of broader DETAILS/Timeline evidence. It reduces
future patch-migration cost while preserving source-specific uncertainty. The
Parser recovers protocol facts only; map knowledge, behavior inference, corpus
acquisition, current-match orchestration, player profiles, and UI remain with their
canonical owners.

## Why now

The repository already contains exact-build framing, packet inventories, build
profiles, a semantic API and capability manifest, generic entity evidence, field
profiling, runtime-image tooling, verified Hero Path/Level/Ward capabilities, a
preserved 16.15 combat surface, partial 16.16 migrations, and regression gates.
The installed runtime and current local Replay corpus bind to exact build
`16.16.805.0442`. These assets make `EXTEND + VALIDATE + GENERALIZE` substantially
more reliable than continuing topic-specific reverse engineering.

## Scope

The stage inventories every observed current-build packet/component route; assigns
an honest semantic status; recovers entity lifecycle, state, and gameplay-event
facts where evidence permits; publishes canonical build-bound schemas and
capabilities; preserves UNKNOWN and negative evidence; and provides a repeatable
full-capability patch-migration/regression path. Existing Hero Combat State work is
one high-priority domain inside this wider baseline, not a separate endpoint.

Protocol-observed monster, structure, ward, and map-mechanic entities are in scope.
Strategic regions, camp polygons, tactical meaning, intent, and player behavior are
not. The suspended `JUNGLE_OBJECTIVE_HOLDOUT_V1` remains inaccessible and is never
read, enumerated, hashed, decoded, modified, tested, or consumed.

## Non-goals and evidence boundary

No network acquisition, Collector mutation, Akari runtime/UI, map-truth ownership,
mechanics-based substitution for absent protocol fields, or behavioral inference is
introduced. Unknown values remain unknown/null, never zero. Correlation, frequency,
names, and structural similarity remain candidate evidence until exact-build layout
and semantic validation justify promotion.

Realtime value classification: `OFFLINE_RESEARCH_ONLY`, with downstream value for
future calibrated `PRE_GAME_AVAILABLE` and `EARLY_GAME_AVAILABLE` outputs.
